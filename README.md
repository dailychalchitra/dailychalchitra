# দৈনিক চালচিত্র (Daily Chalchitra) 👋

**দৈনিক চালচিত্র (dailychalchitra.com)** হলো ওমান থেকে প্রকাশিত একটি জনপ্রিয় বাংলা সংবাদ, সাহিত্য ও সমসাময়িক চিন্তাচর্চার অনলাইন প্ল্যাটফর্ম। ওমান প্রবাসী বাংলাদেশিদের মুখপত্র হিসেবে ২০১৯ সালে এর যাত্রা শুরু হয়। বর্তমানে এটি ওমানের দুকুম, আল-উস্তা গভর্নরেট, ওমান সুলতানাত থেকে পরিচালিত হচ্ছে।
